# modules/tributaria

Carpeta reservada para el material propio del **Área Tributaria** (capturas de pantalla, esquemas y gráficos).

- Cree una subcarpeta `img/` y guarde allí las imágenes, por ejemplo `modules/tributaria/img/t08-constancia.png`.
- Regístrelas en el campo `capturas` del tema correspondiente en `data/tributaria.json` (ver el ejemplo en `modules/contable/README.md`).

**Importante:** no incluya RUC reales, claves SOL, XML ni comprobantes reales.
