# modules/contable

Carpeta reservada para el material propio del **Área Contable**.

- `img/` (créela cuando la necesite): capturas de pantalla de los módulos, por ejemplo `modules/contable/img/c02-paso1.png`.
- Para mostrar una captura en un módulo, regístrela en el campo `capturas` del módulo en `data/contable.json`:

```json
"capturas": [
  { "archivo": "modules/contable/img/c02-paso1.png", "descripcion": "Pantalla de registro de compras" }
]
```

**Importante:** las capturas no deben mostrar datos reales de clientes (RUC, razón social, montos reales, claves).
