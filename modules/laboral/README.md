# modules/laboral

Carpeta reservada para el material propio del **Área Laboral** (capturas de pantalla, esquemas y gráficos).

- Cree una subcarpeta `img/` y guarde allí las imágenes, por ejemplo `modules/laboral/img/l03-alta.png`.
- Regístrelas en el campo `capturas` del tema correspondiente en `data/laboral.json` (ver el ejemplo en `modules/contable/README.md`).

**Importante:** no incluya datos reales de trabajadores, planillas ni documentos de identidad.
