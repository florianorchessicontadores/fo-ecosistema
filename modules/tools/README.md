# modules/tools (Etapa 3)

Carpeta reservada para el código de las **calculadoras de FO Tools**.

Cada herramienta tendrá su propio archivo JavaScript aquí (por ejemplo `calc-igv.js`) y sus parámetros en un archivo JSON, separando siempre el código de los valores legales para poder actualizarlos tras una revisión humana.

El diseño previsto de cada herramienta está en `data/tools.json`. No se programan hasta verificar los parámetros legales vigentes.
