# assets/images

Aquí se guardan las imágenes de la plataforma.

## Logotipo oficial
1. Copie el archivo del logotipo en esta carpeta (por ejemplo `logo.png`).
2. Abra `data/site.json` y cambie `"logo": null` por `"logo": "assets/images/logo.png"`.

El logotipo aparecerá en el menú lateral. No se ha creado ni inventado ningún logotipo.
