# assets/docs

Carpetas de la **Biblioteca Profesional**, una por categoría:

- `manuales-contasis/`
- `procedimientos-internos/`
- `formatos-de-trabajo/`
- `checklists/`
- `modelos-de-documentos/`
- `guias-operativas/`
- `material-de-capacitacion/`

Copie aquí los PDF o imágenes y regístrelos en `data/biblioteca.json` (la pantalla «Biblioteca Profesional» muestra un ejemplo del bloque a agregar).

**Todo lo que se publique en GitHub Pages es público.** Solo suba material no confidencial.
